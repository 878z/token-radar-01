LaunchScope is a radar for protocols building before a token. Its peer-anchor-1 model estimates implied value as TVL times the same-category peer multiple from already-tokenized protocols, adjusted for momentum, seasoning, scale and chain breadth. It includes farm plans with costs and times, while already-tokenized protocols appear separately as peer evidence.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
